JSON Translator

Open a JSON file where the values are still the same as their keys, pick the two languages, and this fills them in with Google Translate. It goes a few lines at a time and waits when Google asks it to.

Nothing is uploaded — the file is read and written in this browser. Code inside {braces} and [brackets] is hidden from the translator and put back untouched, so placeholders survive.
